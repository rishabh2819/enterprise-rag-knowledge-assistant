# IT Security Policy

**Department:** IT / InfoSec
**Last Updated:** 2026-05-14
**Access Level:** All Employees

## 1. Password Requirements
- Minimum 14 characters, including uppercase, lowercase, number, and symbol.
- Passwords must be rotated every 180 days.
- Multi-factor authentication (MFA) is mandatory for all corporate accounts.

## 2. Device Policy
- Only company-issued or company-approved (BYOD-enrolled) devices may access internal systems.
- All laptops must have full-disk encryption and endpoint protection software installed.
- Lost or stolen devices must be reported to IT Security within 1 hour of discovery.

## 3. Data Classification
| Level | Description | Example |
|---|---|---|
| Public | No restriction | Marketing material |
| Internal | Employees only | Internal wiki pages |
| Confidential | Need-to-know basis | Financial reports |
| Restricted | Named individuals only | Customer PII, source code secrets |

## 4. Access Control
Access to systems follows least-privilege principle. Access reviews are conducted quarterly. Terminated employees have access revoked within 1 hour of offboarding.

## 5. Incident Reporting
Suspected security incidents (phishing, malware, unauthorized access) must be reported immediately to security@company-internal.example via the IT Helpdesk portal.

## 6. Third-Party Software
Employees must not install unapproved software on company devices. Requests for new software go through the IT procurement request form.
